# 寰途智能旅行策划师｜队友预览包

这是寰途更新分支的脱敏预览包，用于新比赛内部讨论和试用。原上交审核版本没有被修改。

## 本地启动

需要 Node.js 22 或更高版本，项目不需要安装第三方依赖：

```powershell
node server.mjs
```

然后打开：`http://127.0.0.1:8788`

也可以运行 `启动寰途.ps1`。

## 可以重点体验

- 保留原有旅行规划表单和逐日行程生成。
- 搜索 Agent：景点、交通、酒店评价等来源检索，按运行配置启用。
- 英德知识库：搜索结果和确认事实可按城市沉淀、复用、刷新或删除。
- 天气：Open-Meteo 实时预报，超出范围时显示气候参考。
- 地图、路线图、日历导出、JSON 导入导出。
- 公开试用模式、任务进度、取消任务和来源状态标注。

## 验证状态

- Node 测试：154/154 通过。
- 浏览器 Playwright 冒烟：当前打包环境未运行，因为没有预装 Python Playwright。
- 实时搜索、天气和地图是否成功，取决于网络、运行配置和对应服务响应。
- 酒店库存、房态、票价、营业时间和班次仍必须以官方页面再次核实。

## 文件说明

- `server.mjs`：后端服务和 API。
- `public/`：网页、交互逻辑和地图资源。
- `knowledge/`：规划规则、目的地资料和来源政策。
- `tests/`：离线单元测试与接口测试。
- `验收截图/`：已有页面和流程截图。
- `更新说明-20261117.md`：本轮更新记录。

## 讨论边界

这个包用于队友预览和方案讨论，不代表已经完成新比赛提交，也没有包含任何模型密钥、访问码或服务器登录信息。需要联网体验时，请由运行者在本机配置自己的模型服务。
